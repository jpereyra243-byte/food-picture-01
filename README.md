# Tonkotsu Ramen Noodle Pull (`food-picture-01`)

An entry for the make.fun `food-picture-01` competition ("Make the best-looking food picture").

## Overview
- Features a steaming artisanal Tonkotsu Ramen bowl with a tall glossy noodle pull, torched glazed chashu pork belly, molten seasoned ajitama egg, fresh scallions, toasted nori, and rich aromatic broth droplets.
- Deterministic output written to `/output/entry.png` (`1024 x 1024`, 393 KB).

## Usage
```bash
python3 main.py
```
